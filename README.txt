TRYTECHO WEBSITE

Files:
- index.html: responsive single-page website
- assets/office-scene.webp: hero office background image

Preview locally:
1. Extract the ZIP if using the packaged download.
2. Open index.html in a browser, or run a local server from this folder:
   python -m http.server 8000
3. Open http://localhost:8000

Before publishing:
- In index.html, search for CONTACT_EMAIL and replace hello@trytecho.com with an inbox you control.
- The hero image contains the TryTecho wall-sign from the visual concept; the header logo, text, cards and buttons are real HTML/SVG elements.
- The 100+, 50+, 4.9 and 6+ metrics match the supplied reference mockup. Replace them with verified business figures if they are not accurate.
- The Work cards are labelled as illustrative concepts, not completed client projects.
- Configure hosting and connect a domain/DNS to publish online. This package itself does not publish the site.
